- **Agent (kestrel)**: In-guest process that acts as PID1 in default initramfs mode and proxies OpenAPI calls over vsock.
- **Bridge (vbr0)**: Linux bridge used to connect VM tap devices to the host network.
- **CIDATA**: Volume label for NoCloud seed images used by cloud-init.
- **Cloud-init**: Standard for VM initialization; Volant supports NoCloud via seed image.
- **Deployment**: A named set of identical VM replicas managed by the orchestrator.
- **fledge.toml**: Build-time configuration file defining how to build an image.
- **Image**: A template or blueprint for creating VMs, containing boot media and default configuration. Think Docker image or AWS AMI.
- **Image Registry**: Storage for installed image manifests, managed by volantd.
- **Init modes**: default/custom/none — control PID1 behavior in initramfs builds.
- **Initramfs**: Compressed RAM filesystem used as initial userspace; boots in <150ms.
- **Manifest (manifest.json)**: JSON document generated by fledge describing image runtime, boot media, devices, and defaults.
- **manifest.toml**: Runtime defaults configuration file defining default resources, environment, and workload.
- **Override**: Instance-specific configuration provided via CLI flags (--cpu, --memory, --env, --port) that takes precedence over manifest defaults.
- **Rootfs**: A bootable filesystem image derived from an OCI image (squashfs by default, or ext4/xfs/btrfs for legacy use).
- **Tap**: TUN/TAP device used to provide Ethernet to a microVM.
- **VM**: Virtual Machine; a running instance created from an image. Think Docker container or EC2 instance.
- **Vsock**: Virtio socket channel used for host↔guest communication without Ethernet.
- **VFIO**: Linux kernel framework for PCI passthrough; used for GPUs/devices.
